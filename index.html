Firestore Security Rules

Copy & paste ke Firebase Console → Firestore Database → Rules.

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Cukup authenticated — siapa yang login di Firebase Console yang Anda pegang saja
    function isAdmin() {
      return request.auth != null;
    }

    match /students/{nis} {
      allow read: if true;
      allow write: if isAdmin();
    }

    match /attendance/{docId} {
      allow read: if true;
      allow write: if isAdmin();
    }

    match /settings/{docId} {
      allow read, write: if isAdmin();
    }

    match /piket/{docId} {
      allow read, write: if isAdmin();
    }
  }
}

Catatan: rules ini membuat Portal Cek Absensi publik memakai defaultConfig (branding default). Jika ingin branding tampil di portal, buat dokumen settings/public dengan allow read: if true;.

Formula & alat simulasi

    

      

        
 Formula
// Poin maksimal
max = siswa × hari × poin_hadir
// Poin diperoleh
actual = Σ poin per status
// Persentase
% = (actual / max) × 100

        
 Catatan
  • Hanya siswa aktif yang dihitung
  • Hari efektif = hari unik dengan data absensi
  • Persentase tertinggi per tingkat = Juara 1
